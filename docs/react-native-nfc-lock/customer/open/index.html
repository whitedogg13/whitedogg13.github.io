REAL LOCKS CUSTOMER

準備開啟你的 App。

如果這個連結留在網頁，請依下方方式繼續使用 Real Locks Customer。

  1. 已經安裝 App

    請從手機主畫面開啟 App，也可以從外部訊息或郵件再次點擊這個連結。瀏覽器與你的開啟偏好可能影響連結的處理方式。

  2. 還沒有安裝

    請向管理員索取適用於 iOS 或 Android 的安裝方式。安裝後，手動開啟 App，或從訊息與郵件再次點擊連結。

  3. 開始使用你的鎖

    依 App 指示匯入認證卡，再由你選擇操作並感應實體鎖。

連結只會開啟或喚回 App，不會自動開鎖、匯入認證資訊或啟動 NFC 操作。
